Interface de calcul :
scoring_model.default_model(provenance=None), validate_model(model), revise_model(model, penalty_n=1, penalty_d=2, intent='...'), validate_case(case), evaluate(model,case).

Le seuil est une chaîne décimale exacte. Les résultats distinguent les rationnels exacts et les chaînes de présentation à deux décimales.
scoring_rust.emit_rust(model) -> code Rust ; encode_case(case) -> entrée fermée ; parse_result(stdout) -> résultat contrôlé.
